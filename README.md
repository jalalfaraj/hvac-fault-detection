# HVAC Fault Detection using Semi-Supervised Learning

This project demonstrates a novel approach to detecting subtle HVAC system faults using a custom semi-supervised algorithm combining k-NN search with unsupervised clustering.

🏆 Published in IEEE (2021): https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=10026516

## Highlights
- Built a scalable semi-supervised fault detection algorithm
- Reduced labeling burden while improving fault classification
- Applied domain knowledge from mechanical systems and machine learning
